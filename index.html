Projects

Spartan Touchdown

A 2D platformer game where you play as sparty and have to make it to the goalpost at the end of the level. In-between the start and the goalpost you will encounter enemeis (other unviersity mascots) and must grab power ups to make it past them. This was developed with a team of five members including myself over the span of about two months.

JBBNS Image Handling

An image storage website with google OAuth integration. All backend was done using python and was hosted using Microsoft Azure. The website had a SQLite database that was used to associate images with user accounts. This project was completed with a team of two other people and took roughly a month and a half.
